# assets

## logo-fixy.png  ← falta este archivo

Colocá acá el archivo oficial del logo de Fixy con el nombre exacto **`logo-fixy.png`**.

Se usa tal cual, sin recortes, sin filtros y sin cambios de proporción: la hoja de
estilos solo le fija el ancho y deja la altura automática.

Mientras el archivo no esté, el sidebar muestra un recuadro neutro con la leyenda
"Colocar logo en assets/logo-fixy.png". No hay ninguna recreación ni imitación del
logo en este proyecto.

Si el archivo oficial es SVG en lugar de PNG, subilo como `logo-fixy.svg` y cambiá
la extensión en la línea `<img class="brand__logo" ...>` de `index.html`.

## favicon.svg

Marca neutra (recuadro azul Fixy con un punto amarillo). No es el logo de Fixy y no
pretende serlo: es solo el ícono de la pestaña del navegador. Se puede reemplazar
por el ícono oficial cuando esté disponible.
